# کاتالوگ ریسک و سناریوهای شکست (FMEA)

> **وضعیت:** تأییدشده (G0) · **نسخه:** v1.0 · **تاریخ:** ۱۴۰۵/۰۹/۰۲
> **خروجی ۷ از ۱۰** — مبنا: R-01..R-15، E1..E15، FR-*، ADRها
> **مالک `FM-*`، رفتار فوری و مسیر بازیابی.**

## ۰. راهنما
**شدت:** S1 فاجعه (داده مالی/موجودی نادرست، نشت) · S2 توقف عملیات/آسیب مشتری · S3 اختلال محدود · S4 نارضایتی جزئی.
هر خطای S1/S2 باید کشف خودکار **و** Runbook داشته باشد.
