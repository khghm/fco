# استانداردهای UI و Micro-UX — فارسی، RTL، شمسی، اعداد

> **وضعیت:** تأییدشده (G0) · **نسخه:** v1.0 · **تاریخ:** ۱۴۰۵/۰۹/۰۲
> **خروجی ۶ از ۱۰** — این سند قانون است؛ مؤلفه ناسازگار در بازبینی رد می‌شود.

## ۰. پنج اصل
صفر ابهام (واحد پول، تقویم، نتیجه دکمه) · کار روزمره سریع‌تر از کار نادر · خطا بخشیدنی، داده نه · قابل‌اتکا برای ۸ ساعت کار · یک منبع حقیقت برای قالب‌بندی.

## ۱. فارسی و RTL

| موضوع | استاندارد |
|---|---|
| فونت | Vazirmatn self-hosted (woff2، swap، زیرمجموعه فارسی/لاتین) |
| جهت | `dir="rtl"`؛ چیدمان با Logical Properties (`margin-inline-start`, `inset-inline-end`) |
| آینه‌سازی | فقط چیدمان؛ آیکون‌های معنادار (پخش، فلش بازگشت) کورکورانه آینه نمی‌شوند |
| متن ترکیبی | bidi isolation برای کد/SKU/ایمیل/URL/کارت؛ علائم پایانی فارسی |
| نرمال‌سازی | ي/ك عربی → ی/ک فارسی؛ ذخیره با شکل استاندارد |
| نیم‌فاصله | نرمال‌سازی در ایندکس جست‌وجو، نمایش صحیح در متن تولیدی |
| علائم | «،» و گیومه فارسی؛ فاصله باریک قبل از ٪ |
| اندازه | متن اصلی ≥ ۱۴px، خط‌ارتفاع ۱.۷ |
| اعداد | نمایش فارسی، ذخیره/محاسبه لاتین |
| لاتین در متن فارسی | بازه `dir="ltr"` روی همان عبارت، نه کل پاراگراف |

## ۲. تقویم شمسی

| موضوع | قاعده |
|---|---|
| ذخیره | Timestamp UTC؛ هیچ رشته شمسی در DB |
| تبدیل | یک سرویس تاریخ واحد (`Asia/Tehran`، کبیسه، مرز روز) |
| نمایش | «۲ آذر ۱۴۰۵» یا «۱۴۰۵/۰۹/۰۲ · ۱۴:۳۰» |
| نسبی | امروز/دیروز/۳ روز پیش فقط نزدیک؛ دقیق در tooltip |
| انتخاب سریع | امروز · دیروز · هفته · ماه جاری · ماه گذشته · سفارشی · فصل |
| مرز روز | «امروز» = ۰۰:۰۰–۲۴:۰۰ تهران |
| مرتب‌سازی | بر timestamp واقعی نه رشته |
| تعطیلات | جدول نسخه‌دار؛ مبنای SLA و زمان‌بندی |
| خروجی | ستون شمسی خوانا + ستون ISO |
| ورودی | Picker شمسی + تایپ دستی معتبر + جلوگیری از بازه معکوس |

## ۳. اعداد و مبالغ

| موضوع | قانون |
|---|---|
| ارقام | پذیرش فارسی/لاتین؛ تبدیل به لاتین در پردازش |
| هزارگان | فقط نمایش؛ در فوکوس حذف، بعد از blur بازگشت بدون پرش نشانگر |
| اعشار | فقط درصد/وزن/ابعاد؛ مبلغ بدون اعشار |
| واحد پول | همیشه همراه مبلغ؛ هیچ مبلغ بی‌واحد |
| بدون هزارگان | تلفن، کد پستی، SKU، بارکد، کارت، رهگیری (LTR و قابل کپی) |
| منفی | فقط فیلد مجاز + تأیید واضح |
| حداقل/حداکثر | کلاینت + سرور با پیام دقیق |
| Paste | پذیرش تمیز؛ فیلتر بدون حذف بی‌صدای کل مقدار |
| درصد | ۰..۱۰۰ با «٪»؛ سقف سیاست |
| موبایل | نرمال‌سازی +۹۸/۰۰۹۸؛ نمایش ماسک‌شده در لیست |
| کد پستی | ۱۰ رقم با اعتبارسنجی قالب |

## ۴. قرارداد جدول مدیریتی

صفحه‌بندی سروری + شمار کل + «آخرین به‌روزرسانی» · جست‌وجوی Debounce روی فیلد ایندکس‌شده · فیلتر سریع + پیشرفته · نمای ذخیره‌شده شخصی · انتخاب/ترتیب/عرض ستون با مجوز · انتخاب چندگانه + عملیات گروهی با گزارش نتیجه · وضعیت با رنگ + متن · Loading/Skeleton/Empty/Error/Unauthorized · خروجی Excel/CSV در پس‌زمینه + ثبت Audit · حفظ فیلتر از طریق URL · دکمه‌های عملیات با مجوز (و بررسی سرور).

## ۵. فیلتر و Debounce

Debounce متن ۳۰۰ms (قابل تنظیم، مبتنی بر اندازه‌گیری) · Select بدون Debounce · AbortController · مقایسه sequence برای جلوگیری از پاسخ قدیمی · حذف درخواست تکراری با پارامتر یکسان · Enter/دکمه در فرم پیشرفته · محلی فقط برای داده صفحه · همه فیلترها در URL.
**Debounce جایگزین بهینه‌سازی Query نیست.**

## ۶. فرم‌ها

اعتبارسنجی blur/submit + فوکوس به اولین خطا · نگاشت خطای سرور به فیلد · حفظ داده پس از خطا · ضد دوبار ثبت (کلاینت + Idempotency سرور) · هشدار خروج با تغییرات · Auto Save فقط محتوایی · فرم طولانی مرحله‌ای با ذخیره تدریجی · پیش‌نمایش قبل از عملیات حساس · تأیید دومرحله‌ای برای مالی/انباری · کنترل دسترسی فیلد · راهنمای کوتاه فارسی.

## ۷. بازخورد سیستمی

Toast ۳–۵ ثانیه · موفقیت مهم با لینک سند · عملیات طولانی با Progress و امکان ترک صفحه · خطای قابل‌بازیابی + تلاش مجدد + شناسه · خطای غیرقابل‌بازیابی + راهنمای اقدام · Empty State با دلیل و اقدام · تداخل هم‌زمانی با نمایش تفاوت · نبود شبکه با نوار وضعیت (بدون ثبت مالی آفلاین).

## ۸. دسترس‌پذیری

کنتراست AA · صفحه‌کلید کامل (جدول، فرم، مودال، Esc) · فوکوس نمایان و بازگشتی · Screen Reader با Label/اعلام تغییر · رنگ تنها حامل اطلاعات نباشد · هدف لمسی ≥ ۴۴px · زوم تا ۲۰۰٪ · `prefers-reduced-motion` · هیچ تایمر آزاردهنده؛ Timeout با هشدار.

## ۹. تنظیمات شخصی vs کسب‌وکار

| مجاز (شخصی) | ممنوع |
|---|---|
| تراکم، ستون‌ها، تعداد ردیف | نرخ مالیات، سیاست تخفیف |
| بازه پیش‌فرض گزارش | حساب‌ها و نگاشت رویداد |
| میانبرها | سیاست موجودی و نقطه سفارش |
| ترجیحات اعلان | نقش/مجوز |
| حالت نمایش | تعطیلات و ساعات کاری |

## ۱۰. بودجه عملکرد رابط (آزمون‌نشده)

LCP < ۲.۵s موبایل · INP < ۲۰۰ms · CLS < ۰.۱ · جدول ۵۰ ردیف < ۱s پس از پاسخ · تایپ ۱۰ کاراکتر ≤ ۱–۲ درخواست نهایی · JS اولیه فروشگاه حداقلی.
**تثبیت پس از اندازه‌گیری در `PERFORMANCE_BUDGETS.md`.**
