# Architecture Decision Records

هر تصمیم معماری معنادار یک فایل مستقل با شماره دارد. ADR تغییرناپذیر است؛ تصمیم جدید = ADR جدید با `Supersedes`.

## قالب هر ADR

```
# ADR-00X — عنوان
وضعیت: پیشنهادی | پذیرفته‌شده | رد‌شده | جایگزین‌شده توسط ADR-00Y
تاریخ: …
زمینه / گزینه‌ها / تصمیم / دلیل / پیامدها / شرط بازبینی
```
