# دیزاین‌سیستم (Design System)

> **وضعیت:** تأییدشده (G0) · **نسخه:** v1.1 · **تاریخ:** ۱۴۰۵/۰۹/۰۳
> **مرجع بالادست:** `quality/MICRO_UX_STANDARDS.md` (قانون تعامل) و `UX-03/PERSIAN_UX_STANDARDS.md` (قانون زبان)
> **جایگاه:** این سند **توکن‌ها و مؤلفه‌ها** را تعریف می‌کند تا دو اپ (`apps/shop`، `apps/admin`) از یک منبع ظاهر بگیرند.
> **مالکیت کد:** `packages/ui` (مؤلفه‌ها) + `packages/formatting` (تاریخ/عدد/مبلغ) — هیچ استایل محلی خارج از این بسته‌ها مجاز نیست.

---

## ۱. اصول طراحی

1. **وضوح قبل از زیبایی:** عدد، واحد، تاریخ و نتیجه دکمه باید بدون تفسیر فهمیده شوند.
2. **یک منبع حقیقت برای ظاهر:** رنگ/فاصله/تایپ فقط از توکن؛ مقدار خام در کامپوننت ممنوع.
3. **RTL بومی، نه آینه‌شده:** چیدمان با Logical Properties نوشته می‌شود، نه `left/right`.
4. **حالت‌ها بخشی از مؤلفه‌اند:** مؤلفه بدون `loading/error/empty/disabled/read-only` تحویل نمی‌شود.
5. **تراکم برای کار روزمره:** پنل مدیریت متراکم، فروشگاه نفس‌گیر.
6. **دسترس‌پذیری حداقل نیست، پیش‌فرض است:** کنتراست AA، صفحه‌کلید کامل، هدف لمسی ≥۴۴px.
7. **حرکت با معنا:** انیمیشن فقط برای بیان تغییر وضعیت؛ با `prefers-reduced-motion` خاموش.

## ۲. توکن‌ها (منبع: `packages/ui/tokens.ts`)

### ۲.۱ رنگ
| توکن | کاربرد | قاعده |
|---|---|---|
| `color.bg.canvas` | پس‌زمینه صفحه | — |
| `color.bg.surface` | کارت/پنل | — |
| `color.bg.subtle` | ردیف یک‌درمیان، ناحیه غیرفعال | — |
| `color.text.primary` | متن اصلی | کنتراست ≥ 4.5:1 |
| `color.text.secondary` | توضیح | ≥ 4.5:1 |
| `color.text.disabled` | غیرفعال | فقط برای غیرفعال |
| `color.border.default` / `.strong` | مرز | — |
| `color.brand.primary` / `.hover` / `.active` | کنش اصلی | یک رنگ اصلی در کل محصول |
| `color.status.success` / `.warning` / `.danger` / `.info` | وضعیت | **همیشه با متن/آیکون، نه فقط رنگ** |
| `color.money.positive` / `.negative` | مبلغ | علامت +/− هم نمایش داده شود |

**قاعده:** رنگ هرگز تنها حامل معنا نیست (دسترس‌پذیری + چاپ). مقادیر دقیق در کد تعریف و در Storybook مستند می‌شوند، نه در این سند (برای جلوگیری از دو منبع حقیقت).

### ۲.۲ تایپوگرافی
| توکن | اندازه | کاربرد |
|---|---|---|
| `font.family.fa` | Vazirmatn (self-hosted، woff2) | همه متن فارسی |
| `font.family.mono` | monospace با پشتیبانی لاتین | SKU، کد، لاگ |
| `text.display` | ۲۸–۳۲px | عنوان صفحه داشبورد |
| `text.h1` | ۲۴px | عنوان صفحه |
| `text.h2` | ۲۰px | بخش |
| `text.h3` | ۱۶px | زیربخش |
| `text.body` | ۱۴–۱۵px، line-height ۱.۷ | متن اصلی |
| `text.caption` | ۱۲–۱۳px | راهنما، برچسب |
| `text.money` | ۱۶px tabular | مبالغ در جدول |
| `text.numeric` | tabular-nums | اعداد هم‌تراز |

**قواعد:** اعداد **همیشه** tabular در جدول/مالی · متن لاتین داخل فارسی در بازه `dir="ltr"` · هیچ متنی زیر ۱۲px · `letter-spacing` فارسی خنثی.

### ۲.۳ فاصله، شعاع، سایه، لایه
| مقیاس | مقدار |
|---|---|

### ۲.۴ حرکت
`duration.fast 120ms` · `duration.base 200ms` · `easing.standard cubic-bezier(.2,0,0,1)` · همه تحت `prefers-reduced-motion`.

## ۳. شبکه و چیدمان

| موضوع | قاعده |
|---|---|
| Breakpoint | `sm 640` · `md 768` · `lg 1024` · `xl 1280` · `2xl 1536` |
| فروشگاه | Mobile-first؛ گرید محصول ۲/۳/۴ ستون |
| پنل | Desktop-first؛ SideNav ثابت (≥lg)، Drawer در کوچک‌تر |

| Sticky | هدر جدول و نوار فیلتر در لیست‌های بلند |

## ۴. کاتالوگ مؤلفه‌ها

هر مؤلفه، **همه** حالت‌ها را دارد: `default · hover · focus-visible · active · disabled · loading · error · read-only · empty` (اگر معنا دارد).

### ۴.۱ ورودی‌ها
| مؤلفه | نکته ایرانی/فارسی |
|---|---|
| `TextInput` | پشتیبانی paste تمیز، RTL، شمارش کاراکتر اختیاری |
| `NumberInput` | پذیرش ارقام فارسی/لاتین، بدون هزارگان در فوکوس |
| `CurrencyInput` | ریال/تومان صریح، جداکننده نمایشی، بدون اعشار |
| `PercentInput` | ۰..۱۰۰، «٪» با فاصله باریک |
| `PhoneInput` | پذیرش `+98`/`0098`/`0…`، نرمال‌سازی به `09xxxxxxxxx` |
| `PostalCodeInput` | ۱۰ رقم، LTR، بدون هزارگان |
| `SkuInput` | LTR، uppercase، بدون فاصله، monospace |
| `SearchInput` | debounce ۳۰۰ms، دکمه پاک‌کردن، نتیجه `empty` صریح |
| `Textarea` | شمارش، ارتفاع خودکار با سقف |
| `Select` / `Combobox` | جست‌وجوی سرور برای لیست بزرگ، حالت «بدون نتیجه» |
| `Checkbox` / `Radio` / `Switch` | هدف لمسی ≥۴۴px، برچسب کلیک‌پذیر |
| `FileUploader` | نوع/حجم، پیش‌نمایش، حذف قبل از آپلود، نوار پیشرفت، خطای صریح |
| `ScanField` | فوکوس پایدار، بازخورد صوتی قابل خاموش‌کردن، ورود دستی با دلیل |

### ۴.۲ نمایش داده
| مؤلفه | الزام |
|---|---|
| `DataTable` | صفحه‌بندی سرور + شمار کل + ستون مرتب‌شدنی (whitelist) + حالت‌های کامل + انتخاب چندگانه با گزارش نتیجه |
| `Pagination` | شمارش «۱–۵۰ از ۱۲۳۴»، keyset در فید |
| `MoneyCell` | واحد صریح، tabular، منفی با رنگ **و** علامت |
| `DateCell` | شمسی کوتاه + tooltip ISO، مرتب‌سازی بر timestamp |
| `StatusBadge` | متن + رنگ + آیکون، بدون اتکا به رنگ |
| `StatusStepper` | مسیر وضعیت سفارش/مرجوعی با گام فعلی |
| `QuantityStepper` | حداقل/حداکثر، ورود دستی، حالت «بیش از موجودی» |
| `Timeline` | تاریخچه رویداد (order_events، audit) با actor و زمان |
| `DiffViewer` | قبل/بعد تغییر (Audit، قیمت) |
| `EmptyState` | دلیل + اقدام بعدی، نه تصویر تنها |
| `Skeleton` | شکل محتوا، نه اسپینر تمام‌صفحه |
| `ErrorState` | پیام فارسی + `request_id` + تلاش مجدد |
| `Chart` | محور شمسی، منبع و بازه در پایین نمودار |

### ۴.۳ بازخورد و ناوبری
`Toast` (۳–۵ ثانیه، موفقیت با لینک سند) · `InlineError` (کنار فیلد) · `Alert` · `Modal` (فقط تأیید/ویرایش کوتاه) · `Drawer` (جزئیات بدون ترک لیست) · `ConfirmDialog` (با پیامد صریح) · `ProgressBar` · `Tabs` · `Breadcrumb` · `SideNav` · `CommandPalette` (میانبر عملیات) · `Tooltip` (توضیح، نه اطلاعات حیاتی).

### ۴.۴ دامنه‌ای
`StockCard` (موجودی/رزرو/قابل فروش به تفکیک) · `PriceHistory` (نسخه‌ها با تاریخ اعتبار) · `PaymentStatus` (شامل Unknown) · `ShipmentTracker` · `ReturnWizard` · `ApprovalInbox` (اقلام در انتظار تأیید) · `AuditLogViewer` · `SettingEditor` (با پیش‌نمایش اثر و تاریخ اعتبار).

## ۶. دسترس‌پذیری (الزامات قابل‌سنجش)

| مورد | حد |
|---|---|
| کنتراست متن | ≥ 4.5:1 (متن کوچک)، ≥ 3:1 (بزرگ) |
| فوکوس | نمایان، حداقل ۲px، بازگشت پس از بستن مودال |
| صفحه‌کلید | Tab/Shift+Tab، Esc، Enter، فلش در جدول/منو |
| Screen reader | `label` هر فیلد، `aria-live` برای Toast/خطا، `role` جدول |
| هدف لمسی | ≥ ۴۴×۴۴px |
| زوم | تا ۲۰۰٪ بدون شکست چیدمان |
| رنگ | هیچ اطلاعاتی فقط با رنگ |
| فرم | پیام خطا مرتبط با فیلد، فوکوس به اولین خطا |
| حرکت | احترام به `prefers-reduced-motion` |

## ۷. قواعد کد و مالکیت

| قاعده | جزئیات |
|---|---|
| ساختار | `packages/ui/components/<Component>/` با `Component.tsx`, `Component.stories.tsx`, `Component.test.tsx`, `index.ts` |
| استایل | توکن‌محور؛ هیچ `#hex`/`px` پراکنده در کامپوننت |
| API مؤلفه | props صریح، بدون `any`، بدون استایل بیرونی از مصرف‌کننده (به‌جز `className` کنترل‌شده در موارد مستند) |
| تغییر شکننده | نسخه‌بندی `packages/ui`؛ حذف prop = تغییر major داخلی |
| بازبینی | هر مؤلفه جدید نیازمند نمونه Storybook + حالت‌های کامل + بازبینی دسترس‌پذیری |
| مستندسازی | یک صفحه نمونه برای هر الگوی صفحه؛ «چطور استفاده نکنیم» هم نوشته شود |
