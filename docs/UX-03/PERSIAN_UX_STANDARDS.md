## ۳. تاریخ و تقویم (تکرار قانون، با جزئیات اجرایی)

| موضوع | قاعده |
|---|---|
| ذخیره | `TIMESTAMPTZ` UTC؛ هیچ رشته شمسی در DB (`ADR-006`) |
| نمایش پیش‌فرض | `۱۴۰۵/۰۹/۰۳` در جدول؛ `۳ آذر ۱۴۰۵` در متن |
| با ساعت | `۱۴۰۵/۰۹/۰۳ · ۱۴:۳۰` (جداکننده وسط، نه خط تیره) |
| نسبی | «امروز»، «دیروز»، «۳ روز پیش» فقط برای ≤۷ روز؛ دقیق در tooltip |
| مرز روز | ۰۰:۰۰–۲۴:۰۰ تهران؛ «امروز» یعنی همین بازه |
| ماه/سال | `آذر ۱۴۰۵`، `سال ۱۴۰۵` |
| بازه | «۱ تا ۳۰ آذر ۱۴۰۵»؛ در فیلتر سریع: امروز/دیروز/هفته/ماه جاری/ماه گذشته/فصل/سفارشی |
| ورودی | Picker شمسی + تایپ دستی معتبر + جلوگیری از بازه معکوس |
| مرتب‌سازی | بر مقدار واقعی، نه رشته نمایشی |
| تعطیلات | جدول نسخه‌دار؛ مبنای SLA و محاسبه روز کاری |
| خروجی | ستون شمسی خوانا + ستون ISO برای ابزار |

**ممنوع:** تاریخ میلادی در UI بدون برچسب صریح؛ تاریخ شمسی در API؛ محاسبه «امروز» در کلاینت به‌تنهایی.

## ۵. متن فارسی: نرمال‌سازی و جست‌وجو

| موضوع | قاعده |
|---|---|
| ی/ک | `ي`/`ك` عربی → `ی`/`ک` فارسی در ذخیره و جست‌وجو |
| نیم‌فاصله | در نمایش حفظ؛ در ایندکس جست‌وجو نرمال‌شده |
| اعراب | حذف در ایندکس، حفظ اختیاری در نمایش |
| اعداد در متن | ورودی فارسی/لاتین پذیرفته و یکسان‌سازی می‌شود |
| مترادف | «شلوار جین»/«جین»؛ جدول نسخه‌دار مترادف‌ها |
| غلط املایی | تحمل خطای محدود (فاصله/حرف جاافتاده) با رتبه‌بندی، نه نتیجه بی‌ربط |
| نتیجه خالی | پیشنهاد اصلاح + محصولات هم‌خانواده + ثبت جست‌وجوی بی‌نتیجه (`FR-2-11`) |
| bidi | SKU/ایمیل/URL/کارت در بازه `dir="ltr"` داخل جمله فارسی |
| علائم | «،» فارسی، گیومه «»، نقطه پایان فارسی |

## ۶. قالب پیام‌ها

### ۶.۱ خطای فرم
```
<مشکل> + <دلیل> + <اقدام>
«شماره موبایل نامعتبر است. باید ۱۱ رقم و با ۰۹ شروع شود.»
```

### ۶.۲ خطای سیستمی
```
<چه شد> + <داده حفظ شد؟> + <شناسه پیگیری> + <اقدام>
«ثبت سفارش انجام نشد. سبد خرید شما حفظ شده است.
 شناسه پیگیری: 6f1c2a. دوباره تلاش کنید یا با پشتیبانی تماس بگیرید.»
```
**ممنوع:** «خطای داخلی سرور»، «Error 500»، نام جدول/ستون، پیام خام درگاه، Stack Trace.

### ۶.۳ موفقیت
```
<نتیجه> + <سند/شناسه> + <قدم بعدی>
«سفارش ثبت شد. کد سفارش: FCO-1405-000123 — مشاهده سفارش»
```

### ۶.۴ تأیید عملیات حساس
```
<اثر دقیق> + <بازگشت‌پذیری>
«با تأیید این تعدیل، موجودی ۵ عدد کم می‌شود و سند گردش ثبت می‌گردد.
 این عملیات با سند اصلاحی قابل جبران است، حذف نمی‌شود.»
```

### ۶.۵ پیامک مشتری (الگو)
| رویداد | الگو (کوتاه، با کد سفارش) |
|---|---|
| ثبت سفارش | «سفارش شما ثبت شد. کد: {{order_number}}» |
| ارسال | «سفارش {{order_number}} ارسال شد. رهگیری: {{tracking}}» |
| تحویل | «سفارش {{order_number}} تحویل شد. نظر شما برای ما مهم است.» |
| مرجوعی تأیید | «درخواست مرجوعی {{rma_number}} تأیید شد.» |
| استرداد | «مبلغ استرداد سفارش {{order_number}} انجام شد.» |
**قاعده:** بدون لینک کوتاه ناشناس؛ شماره فرستنده ثابت؛ امکان انصراف از پیام‌های تبلیغاتی (نه عملیاتی).

## ۸. دسترس‌پذیری زبان

| مورد | قاعده |
|---|---|
| Screen reader | `lang="fa-IR"`، `dir="rtl"` روی ریشه؛ متن لاتین با `lang="en"` در بازه خودش |
| اعداد | اعلام عدد با واحد («دوازده هزار و پانصد تومان») در جاهای حساس |
| خطا | `aria-live` + پیوند به فیلد |
| عنوان | ساختار `h1..h3` منطقی (نه برای استایل) |
| تصویر | `alt` توصیفی فارسی، نه نام فایل |

## ۱۰. شکاف‌های باز

1. جدول رسمی تعطیلات سالانه (نسخه‌دار) آماده نشده؛ مبنای SLA است.
2. نرخ تبدیل ریال/تومان برای نمایش، سیاست گرد کردن و مرجع آن تصمیم نشده.
3. متن حقوقی رضایت و شرایط مرجوعی نیازمند مشاور حقوقی است.
4. الگوی پیامک نهایی باید با ارائه‌دهنده پیامک (طول/خط) تطبیق داده شود.
