# نقشه جامع قابلیت‌ها — Fashion Commerce OS

> **وضعیت:** تأییدشده (G0) · **نسخه:** v1.0 · **تاریخ:** ۱۴۰۵/۰۹/۰۲
> **خروجی ۲ از ۱۰** — هر ردیف شناسه `FR-*`، اولویت (P0..P3)، فاز و وابستگی دارد و مبنای ماتریس ردیابی است.

## ۰. راهنمای اولویت

| اولویت | معنا |
|---|---|
| P0 | نبودش = خطر امنیتی/مالی/داده یا شکست عملیات اصلی؛ بدون آن استقرار واقعی ممنوع |
| P1 | لازم برای اداره حرفه‌ای کسب‌وکار |
| P2 | بهینه‌سازی، تحلیل، اتوماسیون، بهره‌وری |
| P3 | وابسته به بلوغ کسب‌وکار |

فاز ۱ = هسته فروش/عملیات · فاز ۲ = عملیات سازمانی · فاز ۳ = تحلیل/بهینه‌سازی · فاز ۴ = مقیاس/بلوغ.

## ۱. نقشه وابستگی هسته

```
D1 هویت/مجوز
   └─> D2 کاتالوگ/PIM ──> D3 قیمت/تخفیف
            └─> D4 موجودی/WMS ──> D8 بسته‌بندی ──> D9 حمل
                     ▲                 ▲
        D5 خرید/تأمین ──┘      D6 سبد/Checkout ──> D7 سفارش ──> D10 مرجوعی
                                       │                  │
                                       └──> D13 مالی <───┘
                    D11 CRM / D12 مارکتینگ ──> D14 BI/AI
                                │
                D15 پلتفرم (رویداد، یکپارچگی، رصد) / D16 محتوا-SEO-اسناد
```

**قاعده:** هیچ دامنه‌ای نباید «عدد موجودی» یا «مبلغ مالی» را خودش نگه دارد. D4 مرجع موجودی، D13 مرجع پول.
