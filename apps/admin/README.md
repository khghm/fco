# پنل مدیریت FCO

اسکلت فارسی/RTL پنل مدیریت است. احراز هویت، مجوزها و عملیات مدیریتی هنوز پیاده‌سازی نشده‌اند؛ این اپ در وضعیت فعلی برای استفادهٔ عملیاتی نیست.

از ریشهٔ مخزن اجرا کنید:

```powershell
npm run dev:admin
```

برنامه روی `http://localhost:3000` اجرا می‌شود. برای پیشرفت قابلیت‌ها، قراردادهای نقش و مجوز و معیارهای پذیرش در مستندات پروژه مرجع هستند.
